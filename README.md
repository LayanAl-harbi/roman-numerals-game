# Roman Numerals Game

An interactive educational game for learning Roman numerals from 1 to 50. Explore the symbols, practice reading and writing numerals, and finish with a short quiz.

## Play

Open `index.html` in a modern web browser. The game is a static website and does not require a build step or dependencies.

## What’s inside

- A beginner-friendly lesson for I, V, X, and L, with examples for numbers 1–50.
- Multiple-choice practice with explanations for each answer.
- A writing challenge for constructing XL (40).
- A 10-question quiz with questions in both directions: numbers to Roman numerals and Roman numerals to numbers.
- A responsive layout for desktop, tablet, and phone screens.

## Project files

- `index.html` — page structure and learning screens.
- `styles.css` — visual design and responsive styles.
- `script.js` — numeral explanations, practice, and quiz interactions.
